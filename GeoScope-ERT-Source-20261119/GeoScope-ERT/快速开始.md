# GeoScope ERT 电法教学体验版

## Windows 64 位启动

1. 把 ZIP **完整解压**到有写入权限的本地文件夹，例如文档目录。
2. 双击 `GeoScope.exe`。请将 `_internal` 和 `data` 留在同一级目录。
3. 第一次体验可在「地形」步骤选择「加载完整合成演示」，查看三维地形中的二维电阻率剖面。示例的地下模型和观测为合成数据。

## 试用自己的数据

- 可以导入 GeoTIFF 地形，或者先在局部坐标下处理观测。观测表的格式参考 `data/observation-samples`。
- 导入后核对电极编号、阵列类型、实际间距、视电阻率单位与误差设置，再运行二维反演。需要地图定位时可对测线做地理配准。
- 在测网工作区可组织多条测线。解释结果时请区分二维反演剖面、剖面拼接和联合三维反演。选择「项目 → 保存完整项目包」后可用 `.geoscope` 文件继续工作。

## 示例与许可

本版本用于教学与工作流验证。虚拟校园的地形和建筑布局为示意，圣海伦斯演示的地表为公开 DEM 裁剪。演示中的电阻率异常、测线与观测不属于当地的实测成果。

第三方许可与数据归属见 `third-party-licenses` 和 `data/provenance.json`。GeoScope 自身源码的发布与授权以对应源码仓库的许可证为准。
