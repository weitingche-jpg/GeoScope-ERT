# 第三方组件与示例数据

本包使用 Qt for Python（PySide6 Essentials 6.8.3、Shiboken6 6.8.3）与 Qt 6.8.3。组件许可见本目录及上游项目。Qt 运行库以独立动态库随 `_internal` 分发。

- [Qt for Python 6.8.3 对应源码](https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.8.3-src/)
- [Qt 6.8.3 对应源码](https://download.qt.io/archive/qt/6.8/6.8.3/)
- [Qt 开源分发义务](https://www.qt.io/development/open-source-lgpl-obligations)
- [PySide6 与 Shiboken 许可](https://doc.qt.io/qtforpython-6/licenses.html)
- [pyGIMLi](https://github.com/gimli-org/gimli) 与 [pgcore](https://pypi.org/project/pgcore/1.6.0/) 用于电阻率计算。
- [圣海伦斯地形原始文件](https://github.com/pyvista/data/blob/master/Data/SainteHelens.dem) 由 PyVista 示例数据项目提供。本包使用裁剪后的 GeoTIFF，处理和来源见 `data/provenance.json`。
