# 通用温纳观测表模板

这些文件是**合成示例，不是实测数据**，只用于演示导入格式和错误检查。

## 文件

- `温纳观测模板.csv`：第一行为说明，第二行是表头，A/B/M/N 使用从 1 开始的电极编号，视电阻率单位 Ω·m。
- `温纳观测模板-kΩm.csv`：同一装置，视电阻率单位为 kΩ·m；导入时选择 kΩ·m，程序统一换算为 Ω·m。
- `温纳观测模板.xlsx`：含“观测表”和“错误示例”两个工作表，用于检查切换工作表时表头、单位和排除状态是否正确重置。
- `错误示例.csv`：包含重复组合、非温纳排列、负值和非有限值，导入预览中应逐行显示错误，且只有明确排除所有错误行后才能继续。

## 导入规则

1. 本轮观测导入入口支持 `.xlsx`、`.csv`；使用现有 `point_files.read_tables` 读取，不执行宏或公式。
2. A/B/M/N 必须是 1 基整数，排列必须满足等间隔 A–M–N–B 温纳装置；电极组合不能重复。
3. 视电阻率必须是正的有限数。支持 Ω·m 与 kΩ·m，导入后统一为 Ω·m。
4. 重复组合在所有未排除行之间重新计算，因此可以排除重复组中的任意一行；被排除行不参与导入。
5. 电极数量和基础间距必须由操作者核实；观测表本身不能可靠推断未使用电极或真实间距。
6. 切换工作表或表头会清空旧排除状态，避免把其他表的行号误用到新表。
7. 通用表映射通过后仍进入现有观测确认窗口，核对误差与平地假设；取消不会修改当前项目。

原始仪器 CSV/DAT 不经过这些通用模板规则：识别为仪器导出后仍由 `observed_ert.read_observations` 严格校验，校验失败不会回退到通用表格模式。
